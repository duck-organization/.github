# Hi there 👋

Duck Organization is an organization that mostly focuses on open-source projects, letting others view and contribute to them freely.

## Contributing

Contributing to Duck Organization's projects can be done by forking the repository you are contributing to and creating a pull request!

Some repositories contain a `CONTRIBUTING.md` file, which gives you more detail on how to contribute to that specific repository.

## Links

Duck Organization has a few important links for you!

Our [Discord](https://duckorg.com/discord), our [Status Page](https://status.duckorg.com/), and of course our [Documentation](https://docs.duckorg.com) for the repositories that need it.
